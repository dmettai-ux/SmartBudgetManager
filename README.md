What it does
SmartBudget Manager is an Excel workbook for recording personal income and expenses, grouping expenses by category, checking spending against a budget, and viewing a dashboard with totals and a chart.

What you need
Microsoft Excel 2016, 2019, 2021, or Microsoft 365 (or a compatible spreadsheet application).
SmartBudget_Manager.xlsx
Get started
Open the workbook and enable editing if prompted.
On Categories, review the predefined categories and monthly budget amounts.
On Transactions, add one transaction per row (rows 4–50). Select Income or Expense in Type. For expenses, choose a category and enter the amount in Expense; for income, enter the amount in Income.
Open Dashboard to review total income, total expenses, monthly balance, category totals, chart, and budget status.
Save a copy using File → Save As.
Important notes
Do not overwrite formula cells, especially the Month column or Dashboard calculations.
Enter positive amounts and valid dates. Use the correct Income or Expense column.
The current Dashboard totals all entered transactions; it does not provide a month selector.
The workbook is a basic tracking aid, not professional accounting or tax software.
Worksheets
Dashboard — summary, category budget comparison, chart, and warning status.
Transactions — transaction entry table.
Categories — category names and monthly budget amounts.
